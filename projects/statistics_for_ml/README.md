# 📊 Statistics for Machine Learning

A Python project that demonstrates the fundamental statistical concepts used in Machine Learning. This project calculates key descriptive statistics such as Mean, Median, Mode, Variance, and Standard Deviation for a given dataset and provides a basic interpretation of the results.

---

## 🚀 Features

- Calculate **Mean**
- Calculate **Median**
- Calculate **Mode**
- Calculate **Variance**
- Calculate **Standard Deviation**
- Display a simple interpretation of the dataset
- Clean and beginner-friendly Python implementation

---

## 🛠️ Technologies Used

- Python 3
- NumPy
- Python Statistics Module
