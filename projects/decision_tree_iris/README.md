# 🌳 Decision Tree Iris Classification

A beginner-friendly Machine Learning project that classifies Iris flowers into three different species using the **Decision Tree Classification Algorithm** from Scikit-learn.

This project demonstrates the complete Machine Learning workflow, including data loading, preprocessing, model training, prediction, and evaluation.

---

## 🚀 Features

- Load the Iris dataset
- Split data into training and testing sets
- Train a Decision Tree Classifier
- Predict flower species
- Evaluate model accuracy
- Simple and well-structured Python implementation

---

## 🛠 Technologies Used

- Python 3
- Scikit-learn
- NumPy

## 📊 Dataset

The project uses the built-in **Iris Dataset** available in Scikit-learn.

Dataset contains:

- 150 samples
- 4 input features
- 3 flower species

### Features

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

### Target Classes

- Setosa
- Versicolor
- Virginica

---

## ⚙️ Machine Learning Workflow

1. Load Iris Dataset
2. Split Dataset into Training and Testing Sets
3. Create Decision Tree Model
4. Train the Model using `fit()`
5. Predict Test Data using `predict()`
6. Evaluate Model Accuracy using `score()`


