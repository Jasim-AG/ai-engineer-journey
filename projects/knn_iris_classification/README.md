# 🌸 K-Nearest Neighbors (KNN) - Iris Classification

A Machine Learning classification project that predicts the species of Iris flowers using the **K-Nearest Neighbors (KNN)** algorithm from Scikit-learn.

---

## 📌 Project Overview

This project demonstrates how to build, train, and evaluate a **K-Nearest Neighbors (KNN)** classifier using the famous Iris dataset.

The model classifies Iris flowers into one of three species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

The project also includes model evaluation using:

- Confusion Matrix
- Classification Report
- Accuracy Score

Target Classes:

- Versicolor
- Virginica

---

## ⚙️ Machine Learning Algorithm

Algorithm Used:

**K-Nearest Neighbors (KNN)**

Parameter:

```python
KNeighborsClassifier(n_neighbors=3)
```

The model predicts the class based on the majority vote of the **3 nearest neighbors**.
