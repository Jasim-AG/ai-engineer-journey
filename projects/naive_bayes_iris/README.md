# 📧 Naive Bayes - Iris Classification

A Machine Learning classification project that predicts the species of Iris flowers using the **Gaussian Naive Bayes** algorithm from Scikit-learn.

---

## 📌 Project Overview

This project demonstrates how to build, train, and evaluate a **Gaussian Naive Bayes** classifier using the famous Iris dataset.

The model classifies Iris flowers into one of three species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

The project evaluates the model using:

- Accuracy Score
- Confusion Matrix
- Classification Report

- Iris Virginica

## 🤖 Machine Learning Algorithm

Algorithm Used:

**Gaussian Naive Bayes**

```python
model = GaussianNB()
```

Gaussian Naive Bayes assumes that numerical features follow a **Gaussian (Normal) Distribution**.
